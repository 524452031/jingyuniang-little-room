# 抠绿幕（边缘泛洪版）

这套图都是「纯绿底 + 一个物体」的 AI 生成画。抠图有个坑：

**一刀切**（比如 `g > r + 35` 就算背景）会把**白色物体的阴影**也当成绿幕吃掉。
实测把洗手台右下角咬掉一块，肉眼看不出来，贴进场景才发现缺角。

正确做法是两步：

1. **从画面四边泛洪**，只清掉与边缘连通的绿色（物体内部的绿不会动）
2. 再压掉残留的**绿边**（绿色通道超过 max(r,b) 的部分压回去）

```bash
python key_green.py 输入.png 输出.png
```

用法示例（本仓库的素材都是这样来的）：

```bash
python key_green.py 洗漱-绿幕.png assets/room/act_wash.png
```

**另外一条更重要的经验**：多件物体画在同一张图上时，**不要写算法去拆**。
连通块、按列切、按对角线切都试过，总会把邻居的边角带进来。
让人单独出图，比任何算法都快，也干净。
